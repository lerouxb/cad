A tool options row

Selection filters had nowhere to live: the selection popover only appears after you have selected something, and a filter is what you set before. The fix is one row under the tool line that holds the options for the current tool — and that row turns out to fit the create variants too.

What this study tests

  • One options row, contextual. It sits directly under the tool line and shows only the options the current tool has. line and point have none, so the row collapses and takes no space — the tool line does not move.
  • Selection filters. For select / box / lasso the row holds the filter: all, points, curves, dimensions. With a filter on, the cursor can only pick that kind — hovering a line under points does nothing.
  • The same row holds the create variants. rect → 2-point / centre; circle → centre / 2-point / 3-point; arc → centre / 3-point / tangent. A dashed preview shows what each variant draws.
  • Select other. Where picks overlap — the shared corner is two lines and a point — a small chip at the cursor cycles through them, so an overlap is a choice, not a lottery.

Decided

  • One filter at a time. No multi-select checkboxes — Fusion's set is overkill, and wanting several at once is rare.
  • The select tools come to the model view too, with the filters that make sense there (edges / faces / bodies). The row follows the tool, not the mode — see select-model.html.
  • The create variants share the row. A row whose meaning changes with the tool is not confusing — that is the point of it.
The model-mode filters would be edges / faces / bodies; the sketch filters shown here are the same row with a different set.
