Extrude options

Extrude is where a sketch becomes a body, and it is the feature whose parameters are edited most. This study is the same popup-and-preview grammar as the body tools, applied to a feature: the profile is the source, the solid is the live preview, and the options decide its shape.

What is shown

  • Profile: an input row + list. select switches to the sketch and makes region fills the targets; the form stays open. The list is `Profile N · area · remove`, before the value (see PICKS.md).
  • Start: from the profile plane, or offset by an exact distance. The dashed profile marks where the solid starts.
  • End: blind (a distance), to object (up to a picked body/face), to next (the first surface), or all (through everything). To-object and to-next coincide here because there is one body above; they differ when several are stacked.
  • Taper: a draft angle on the side walls, so the top is smaller (or larger) than the base.
  • Operation: the same four-way row as every solid feature — new body, join, cut or intersect (see BOOLEANS.md). A cut previews the removed material in red; an intersect keeps the overlap and ghosts the rest.

Open questions

  • Do start offset and to-object need a value field plus a pick, or can the pick fill the value (Fusion's "to object" does)?
  • Should the end condition be a segmented row, or a small list like the split-body splitting tool?
  • Taper and to-object can conflict; how is that surfaced without a red error?
Stylised geometry for a design decision, not a real B-rep. The point is the interaction: start, end, taper and operation, previewed live.
