Offset faces

Move a boundary face by a distance and let its neighbours rebuild. This is the tolerance/fit feature — the third most-used operation in the reference part — not a whole-body offset, not a shell and not a press/pull. It is a model-stage feature: select faces in the 3D model, never in the sketch. Select faces, choose offset face…, set distance and direction in a previewed history step.

What moves

Every face moves along its own normal. A planar wall changes an extent; a cylindrical wall changes a radius; a tangent chain moves together. The section is shown edge-on; the actual model is in 3D.

Top face · out / in

Outward grows the body; inward reduces the thickness. The slider ceiling is a hint; the number can exceed it to show a failure.

Hole wall · diameter

When it cannot

Too far, self-intersection, no movement, or a result that is not a closed body is a visible error. The last good body stays; apply is disabled; nothing is silently skipped or substituted.

The rules in one place

  • Select first, offset second. `offset face…` is a feature chip in the face popover, beside `new sketch` and `shell…`; no click starts an offset.
  • One history step, one body. The step modifies the existing body (`→ body`), never creates a new one; select it to edit, suppress or delete.
  • Distance is positive; direction is a flip. `out` / `in` follows each face's normal; the summary shows `+`/`−`.
  • The MeasureField is shared. Adaptive slider ceiling, exact field, number may exceed to surface a failure; never silently clamp.
  • Input faces come from the source prefix. The preview body is the result, not a pick surface; the selected faces stay listed and removable.
  • A cylindrical face gets a diameter readout. `Ø 20.0 → 20.4 mm`, with enlarge/shrink; it is derived, not document state.
  • Chain is a selection helper. It expands to tangent faces; the same distance applies. Kernel support is open.
  • Failure is visible. Too large, self-intersection, no movement or an invalid body keeps the last good body and disables apply; no fallback to a whole-body offset, shell or scale.
  • Roles are re-derived. Downstream face sketches follow the moved face or surface lost support; no silent retarget.
  • Planar and cylindrical first. Other surfaces may fail visibly until the kernel path is proven.

design notes · offset faces

Move the boundary, not the body

The audit found 11 uses of Offset Faces — every one a tolerance/fit adjustment. It is a history step that moves boundary faces and rebuilds their neighbours, not a whole-body offset and not a shell. The feature belongs in the face selection popover beside new sketch and shell.

What this study settles

  • Select first, offset second. The face popover has `offset face…`; the chip starts the draft. No direct feature from a click.
  • One positive distance + out/in. `MeasureField`, an adaptive rail, and a number field that can exceed it to show a failure.
  • The face set is an input row + list. `faces 2 selected`, then `Face 1 · planar · 640 mm² · remove`; the list is before the value and scrolls. See PICKS.md.
  • A cylindrical face gets a diameter readout. The hole/boss case is the tolerance/fit case; show `Ø old → new`.
  • Chain is a selection helper. Tangent-connected walls move together; the kernel support is open.
  • History, roles, downstream. The step is re-editable; face roles are re-derived; lost support is visible.
  • Not a boolean. There is no operation row: out/in is a signed distance, and the preview reuses added/removed/ghost from BOOLEANS.md.
  • Failure is visible. The last good body stays; apply is disabled; no whole-body offset or shell substitute.

Open questions

  • The selected-face-on-a-solid kernel operation is the blocking question. `brepjs` has whole-solid `offset` and a face→shape `offsetFace`, not a solid edit.
  • Does `chain` belong in the offset popover or the face selection popover?
  • Signed distance vs positive + flip in the document?
  • How should the input face ghost and the preview body be layered while picking more faces?
  • Offset a face on a shelled body? Multi-body? Symmetric/two-sided? Defer.
