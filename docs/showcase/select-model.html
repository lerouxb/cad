The same row, the model's filters

The sketch study puts the selection filters in a tool options row under the tool line. This is the other half: the same tools and the same row on the model, where the filters that make sense are different.

What this study tests

  • The row follows the tool, not the mode. select / box / lasso appear in model mode too, and the row under them is the same row the sketch tools use — only its contents change.
  • One filter at a time: all, edges, faces, bodies. No checkbox set. With edges on, a face is not pickable at all; with faces or bodies, edges are not.
  • An edge beats the face behind it. Each edge has a wide invisible hit stroke above the faces, so hovering near an edge highlights the edge and hovering inside a face highlights the face.
  • The body filter picks the whole solid. A face hit becomes a body hit, so the whole plate washes rather than one face.
  • Select other cycles the overlap. Where an edge and a face (or two bodies' edges) overlap, a chip at the cursor lists them and clicking advances.

Notes

  • Two disjoint plates, so bodies has more than one thing to pick and a body selection is visibly not a face selection.
  • Hidden edges are not drawn, so the pick list is only the edges the view actually shows.
  • Selection opens the same popover family; this study keeps it minimal because the popover is its own study.
The decision this closes: the select tools come to the model view, with their own filters. See TIMELINE.md.
