One tool, several variants

Fusion hides the drawing variants behind press-and-hold flyouts on a single tool button. This study lays them out so the click sequence and the implied construction are visible side by side.

What each variant adds

  • Rectangle: 2-point (two opposite corners), centre (stays centred on the first click), 3-point (a rotated rectangle from an edge and a width).
  • Circle: centre + radius, 2-point diameter, and 3-point (through three points).
  • Arc: 3-point through a mid point, centre + start + end, and tangent (starts tangent to the curve you click).
  • Polygon: inscribed or circumscribed, N sides, centre + vertex (or edge midpoint). This one is live.

Design questions

  • Flyout on press-and-hold, a small variant switcher in the tool line, or one entry per variant? The line is already long.
  • Do the variants need distinct shortcuts, or does the last-used variant stick to the tool key?
  • Should the click sequence be shown in-app (as here) the first time, or is it learnable from the cursor?
The numbered markers are a teaching device, not app chrome: in the app the cursor and a rubber-band preview carry the same information.
