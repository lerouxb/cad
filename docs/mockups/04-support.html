design notes · 04

Start from a face

Choosing a support is a temporary decision, so it gets a temporary surface. The rest of the model goes quiet; the candidate face is the only thing wearing the highlighter.

What this study tests

  • One list, not three dialogs. World planes, planar faces, and datum planes share the same typographic list.
  • Unsupported is visible. The curved face is still listed, but it explains itself instead of failing later.
  • The new step appears in history. It starts as “untitled” and can be named before or after the sketch exists.
  • The model is still the context. Hovering or selecting a row previews the support on the actual body.

Open questions

  • Should a face support default to the face's boundary projected into the sketch?
  • Does “new sketch” need an offset field here, or is that a datum-plane step?
  • How do we show a flipped normal without adding a checkbox?
This is the only moment the model is dimmed. The highlighter is the answer to “where will the sketch live?”
