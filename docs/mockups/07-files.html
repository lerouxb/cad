Files stay local

The filename at the top-left is the file menu. It opens a local file browser, not an account or a cloud project. There is no sharing in this tool.

What this study tests

  • Download is a file action. “Download .cad” writes the document; it is not an export of the solid.
  • Make a copy and rename stay local. They act on the current file without changing its history.
  • The list is navigation. Local files show their name, step count, body count and modification time.
  • No account chrome. No sign-in, no share links, no cloud sync; just this device.

Open questions

  • Should the file list show a tiny geometry thumbnail, or is text enough?
  • Where do downloaded .cad files re-enter the app, if at all?
  • How should a deleted or renamed local file behave in an open tab?
The filename is the only file affordance in the app header. It is deliberately separate from the timeline and from export.
